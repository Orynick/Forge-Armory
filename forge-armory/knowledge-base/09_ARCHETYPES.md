# D2 Archetypes — DPS Reference
> Source: Destiny 2 Endgame Analysis spreadsheet (June 2026 update)
> Mis à jour : Update 9.7.0 (9 juin 2026)

## Colonnes clés
- **Typ BDPS** = Boss DPS typique (rotation soutenue)
- **Boss Total** = Dégâts totaux vs boss (ammo brick complet)
- **Falloff** = Distance de falloff ADS (mètres) — N/A = pas de falloff
- **Tier** : S > A > B > C > D

> `#VALEUR!` = erreur Excel dans la source (swords manquent de données partielles)
> `INF` = arme principale (munitions infinies — boss Total non calculable)
> `?` = valeur Tier non confirmée dans la source
