## Armor Mods — Système Weapon Surge

### Weapon Surge (mods jambes, 3 Energy)

| Stacks | Bonus PvE | Bonus PvP | Durée |
|---|---|---|---|
| x1 | +10% | +3% | ~10s par Armor Charge |
| x2 | +17% | +4.4% | ~20s |
| x3 | +22% | +5.5% | ~30s |
| x4 | +25% | +6% | Via Exotic ou Artifact uniquement |

> **Time Dilation Mod** (class item) : decay time par stack → 15s/18s/20s avec 1/2/3 mods
> **Charged Up Mod** (chest) : max Armor Charges → +1/+2/+3 avec 1/2/3 mods
> Surges d'éléments différents stackent entre eux

### Combos 2pc + 2pc méta

- **2pc Oryx's Memory + 2pc Promised** (King's Fall + Salvation's Edge) : ammo + 25% DR/+7% dégâts, même condition d'activation (kill Elite+)
- **2pc Legacy's Oath + 2pc Smoke Jumper** (Deep Stone Crypt) : builds melee à fort uptime (Solar Titan hammer, Prismatic slide Warlock)
- **2pc Crystocrene + 2pc AION Adapter** : alternative hors-raid au combo King's Fall + Salvation's Edge

### Synergies et interactions notables (testées)

- **Dreambane 2pc** : Unstable Essence réplique le buff des nightmares de la Lune → **+50% dégâts vs Nightmares** (1 153 → 1 730 au sniper), plus besoin de ramasser les essences
- **Pantheos Resplendent 2pc + artifact Curative Orbs** (Slayer Baron Apothecary Satchel) : un finisher compte comme « bris de bouclier » → orb → armor charge → **chaîne infinie de special finishers**
- **Taken King 4pc + Mothkeeper's Wraps** : les kills de la grenade-moth comptent comme ability kills → spawn des Arc moths supplémentaires (« moth maxing »)
- **Great Hunt 4pc** : marche avec les buddies Warlock (Arc Soul, Hellion, Bleak Watcher, Ionic Sentry) → très bon pour build Getaway Artist Prismatic
- **Promised 4pc + Tablet of Ruin (Elemental Supercharger)** : les cibles exhausted tuées avec l'élément du super = grosse regen de super
- **Legacy's Oath 4pc min-max** : + Cuirass of the Falling Star + 200 Super stat + perks artifact super (Thunderous Retort) — missiles ~2 500 dégâts pièce (⚠ le DDC dit 680/missile — à re-vérifier)
- **Iron Battalion** : dispo uniquement pendant Iron Banner (1 semaine sur 4)
- **Circuit 2pc fully revved** : Speed Booster permanent en sprint = +12.5% sprint, +25% jump, **15% DR**
- **Triumphal Anthem 4pc** : resist x4 = **50% DR pendant la glissade** — niche (low-mans, speedruns)
- **Wildwood 2pc** : 25% DR **illimitée tant qu'on reste ADS** après un precision kill
- **Apostate's Blade 4pc** : marche avec les **melees de glaive** ; idéal Solar Titan throwing hammer (20-30 scorch/hit avec Ember of Ashes → ignition en 4 hits) — mais **ICD de 1s**, pas de spam
- **Dark Age 4pc + combination blow loop** (Hunter) : chaque melee kill relance la class ability → un drone de soin spawn à chaque boucle — excellent pour builds melee/sword
- **Spacewalk 2pc + perk Bewildering Burst** : très synergique — les armes primary avec ce perk auto-alimentent le +15% vs disoriented
- **Crota's Memory 4pc** : timers calqués sur Frenzy/Chaos Reshaped → se marie bien avec ces perks (mêmes conditions « in combat »)
- **Circuit 2pc** : la charge monte aussi via **eager edge** et surtout le **boost de sparrow** (le plus rapide)
- **Seventh Seraph 2pc — activateurs complets** : AoE, abilités Solar, armes Seventh Seraph/Ikelos, explosions de Stasis crystals, Sleeper Simulant, Outbreak Perfected
- **Thunderhead 4pc — piste à creuser (Llama)** : maximiser l'uptime de la grenade **Slice Wire** (gros dégâts) pour boucler le refund ~10% (+Demolitionist par-dessus)

### Anti-synergies / pièges confirmés

- **Crota's Memory 2pc ≠ Necrochasm** : les explosions Cursed Thrall du set ne déclenchent PAS le trait Desperation
- **Veritas 2pc** : lié à l'élément du **super** équipé, ne fonctionne PAS avec super Strand/Stasis (Light uniquement) ; le void breach subit le cooldown global de 5s (idem Eutechnology)
- **Circuit 4pc** : le jolt du slide n'a pas assez d'impulse pour chaîner seul — il faut re-damage les cibles
- **First Ascent** : overkill — la Transcendance se charge déjà très vite (suspend + darkness weapon pour le dark meter, AoE GL pour le light meter)
- **Spacewalk 4pc** : le disorient ne dure que ~3s — fenêtre trop courte pour exploiter le 2pc (+15%)
- **Cruel Electrum / Per Audacia** (Trials / Comp) : sans intérêt PvE, et farm Comp très pénible en fin de vie du jeu
