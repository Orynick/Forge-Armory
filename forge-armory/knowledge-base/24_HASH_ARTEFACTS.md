# Hashes des 7 artefacts — miniatures pour le sélecteur

Chaque artefact a 3 hashes candidats (`DestinyInventoryItemDefinition`),
tous partageant le même nom affiché — convention connue du Manifest Bungie
(plusieurs définitions différentes peuvent partager le même texte). Trouvé
via le bouton de diagnostic **🖼️ hashes** (Artefact, mode développement).

✅ **Vérifié par l'utilisateur (25/08)** : sur les artefacts vérifiés, les
3 candidats renvoient tous la MÊME icône — pas un cas où un seul des 3
avait une vraie image et les 2 autres étaient des copies inertes, comme
l'hypothèse de départ le supposait. Le choix entre les 3 est donc sans
conséquence visuelle ; **le premier de chaque liste est retenu** dans le
code (décision de l'utilisateur), par simplicité.
