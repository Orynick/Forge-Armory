Forge Armory (initialement "Destiny 2 Build Analyzer" : ce nom est devenu le sous-titre de l'application depuis le 05/10/2026)

Appli locale (React + Vite + TypeScript) pour étudier et scorer des builds Destiny 2 selon 5 piliers pondérés (poids variables selon le contexte de build : Neutre, Roaming, DPS, PvP), alignée sur le système Armor 3.0 / Monument of Triumph (juin 2026).
L'appli permet aussi de gérer, en local, les Loadouts des personnages et de les partager sous forme de texte brut, images, PDF ou JSON.

Par Orynick/Orygamer.
